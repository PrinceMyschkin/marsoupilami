# MARSOUPILAMI

MARSOUPILAMI is an interactive 3D model of a tethered membrane Mars habitat at 0.85 atm, with 8 m of hanging water pillows for radiation shielding and thermal mass. The geometry follows [Casey Handmer](https://blog.caseyhandmer.com/)’s tethered-dome concept; the water pillows hang in stacked layers inside the membrane, like soup-vendor bags.

Live model: https://princemyschkin.github.io/marsoupilami/
